## Описание проекта

***Проект еще в разработке❗*** 

Полноценной REST приложение с возможностью писать(редактировать и удалять) статьи авторизированным(через Google) пользователям.
В будущем планируется добавить подписки и комментарии для постов, а так же авторизация через другие сервисы.

## Требования к software

- Java OpenJDK 8;
- Apache Maven 3.6.1;
- NodeJs 16.14.0;
- PostgreSQL 14.1.

## Используемый стек технологий

- Java SE;
- Apache Maven;
- Spring Boot;
- Hibernate;
- Thymeleaf;
- Vue;
- Google oAuth2.
